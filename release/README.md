# QN_Automailer EXE 배포 패키지

## 개요
이 패키지는 QN_Automailer의 standalone 실행 파일(EXE)을 포함합니다.  
별도의 Python 설치나 가상환경 설정 없이 더블클릭으로 즉시 실행 가능합니다.

## 시스템 요구사항
- **OS**: Windows 10 이상 (64-bit)
- **SAP GUI**: 설치 및 로그인 상태 필수
- **Outlook**: Microsoft Outlook 설치 필수
- **메모리**: 최소 4GB RAM 권장
- **디스크 공간**: 최소 500MB 여유 공간

## 포함 파일
```
QN_Automailer_v1.0.exe              # 메인 실행 파일
qn_automailer_settings.json          # 기본 설정 파일
README.md                            # 이 파일
MANUAL_KO.md                         # 사용 설명서 (한글)
```

## 설치 및 실행 방법

### 1. 다운로드
이 디렉토리의 모든 파일을 같은 폴더에 다운로드합니다.

### 2. 첫 실행
```
QN_Automailer_v1.0.exe 를 더블클릭
```

### 3. 초기 설정
첫 실행 시 다음 항목을 설정할 수 있습니다:
- **SAP Export 디렉토리**: SAP GUI에서 내보낼 텍스트 파일 경로
- **Plant 코드**: 조회 대상 생산지 코드 (기본값: 2201)
- **메일 수신자**: QN 리포트를 받을 이메일 주소 (세미콜론으로 구분)
- **실행 날짜**: 조회 대상 날짜 (기본값: 오늘)

### 4. 실행
GUI 창에서 **실행** 버튼을 누르면:
1. SAP에서 해당 기간 QN 데이터 조회
2. 기존 메일/텍스트 파일과 비교해 신규/삭제 QN 판별
3. 이전에 보낸 리포트 메일의 스타일 복제
4. 신규 행 추가, 삭제된 행 제거
5. Outlook 메일 작성 창 열기
6. 메일 내용 확인 후 **발송** 버튼으로 전송

## 주요 기능

### ✅ 자동 비교 및 판별
- **신규 QN 감지**: 이전 조회 이후 새로 등록된 QN
- **삭제 QN 감지**: 이전에 있었으나 지금은 없는 QN
- **텍스트 파일 비교**: 이전 내보낸 텍스트 파일과 비교
- **메일 기반 폴백**: 텍스트 파일이 없을 때 가장 최근 발송 메일에서 기준 추출

### 📊 자동 통계 계산
- **D-3C/D-5C/D-8 만족도**: KPI 성과 자동 계산
- **요약 블록**: 메일 상단에 통계 요약 자동 삽입

### 📧 메일 자동화
- **스타일 복제**: 이전 메일 형식 그대로 유지
- **날짜 자동 치환**: 메일 제목/본문에서 이전 날짜 → 현재 날짜로 자동 변경
- **표 자동 정리**: 신규/삭제 반영 후 번호 자동 재정렬

## 문제 해결

### EXE가 실행되지 않습니다
1. Windows Defender 바이러스 백신 확인 (격리된 파일 복원)
2. 관리자 권한으로 실행 시도 (마우스 우클릭 → 관리자로 실행)
3. 최신 Windows 업데이트 확인

### SAP 세션을 찾을 수 없습니다
1. SAP Logon을 열고 대상 시스템에 로그인
2. SAP GUI 메인 창(wnd[0])이 열려있는지 확인
3. SAP → Options → Scripting 메뉴에서 Scripting 활성화 확인

### Outlook 메일이 열리지 않습니다
1. Microsoft Outlook 설치 확인
2. Outlook 메인 창을 먼저 열기 (필수)
3. 보낸 편지함에 이전 메일이 있는지 확인

### 텍스트 파일 비교가 작동하지 않습니다
1. Export 디렉토리 경로 확인 (GUI 설정창에서 수정 가능)
2. 이전 날짜의 텍스트 파일(YYYYMMDD.txt) 존재 확인
3. 텍스트 파일 인코딩 UTF-8 확인

## 로그 파일
플로그램 실행 로그는 콘솔창에 실시간 출력됩니다.  
중요한 로그는 다음과 같습니다:
- `[DELCHK]` — 삭제 QN 판별 결과
- `[PARSE]` — 파일 파싱 결과
- `[MAIL]` — 메일 처리 상태
