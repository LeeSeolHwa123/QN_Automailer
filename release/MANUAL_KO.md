## 프로그램 개요

**QN_Automailer**는 SAP에서 조회한 품질 알림(QN) 데이터를 자동으로 분석하고  
Outlook 메일로 보고서를 생성해 발송하는 업무 자동화 도구입니다.

### 주요 기능

#### 1. SAP 데이터 자동 조회
- ZQCN, ZNOT 트랜잭션에서 자동으로 데이터 조회
- C-Type (C1, C3, C5 등) 및 Q-Type (Q1~Q9) QN 구분 처리
- 조회 기간 및 생산지별 필터링 가능

#### 2. 신규/삭제 QN 자동 감지
- **신규 QN**: 이전 조회 이후 새로 등록된 항목
- **삭제 QN**: 이전에 있었으나 현재는 없는 항목
- 텍스트 파일 기반 비교 (폴백: 메일 기반)

#### 3. Outlook 메일 자동 생성
- 기존 메일 스타일 자동 복제
- 신규 행 추가, 삭제된 행 제거
- 메일 제목 및 본문 날짜 자동 치환
- KPI 통계 자동 계산 및 요약 삽입

#### 4. 메일 발송 전 수정 가능
- 메일이 Outlook에서 열리므로 발송 전 내용 확인/수정 가능
- 필요시 추가 정보 삽입 후 발송

## 설치 및 실행

### 요구사항
- **Windows 10 이상** (64-bit)
- **SAP GUI** 설치 및 로그인
- **Microsoft Outlook** 설치
- **인터넷 연결** (메일 발송 시)

### 설치 단계

#### 1단계: 파일 다운로드
```
release 폴더의 모든 파일을 같은 디렉토리에 다운로드
- QN_Automailer_v1.0.exe
- qn_automailer_settings.json
- README.md
```

#### 2단계: 첫 실행
```
QN_Automailer_v1.0.exe 를 더블클릭
```

**참고**: 
- Windows Defender에서 차단될 수 있습니다. "추가 정보" → "실행" 클릭
- 첫 실행 시 잠시 로딩될 수 있습니다 (정상)

#### 3단계: 초기 설정 입력
프로그램이 실행되면 "설정" 탭에서 다음을 설정해야 합니다:

```
1. SAP Export 디렉토리
   예: C:\Users\[사용자명]\Documents\SAP\SAP GUI
   [찾아보기] 버튼으로 선택 가능

2. Plant 코드
   기본값: 2201
   (SAP에서 사용하는 생산지 코드)

3. 메일 수신자
   예: user1@company.com; user2@company.com
   (세미콜론으로 여러 명 지정 가능)

4. 파일 템플릿 (선택사항)
   기본값: {YYYYMMDD}.txt
   (내보낼 파일명 패턴)
```

## GUI 사용법

### 메인 화면 구성

```
┌─────────────────────────────────────────┐
│  QN_Automailer                          │
├─────────────────────────────────────────┤
│ [설정] [실행] [로그]                     │
├─────────────────────────────────────────┤
│                                         │
│  진행 단계: [████░░░░░░] 40%            │
│                                         │
│  상태: 각 QN의 대응 기한을 확인 중...    │
│                                         │
│  로그 내용:                             │
│  [SAP] 세션 연결됨: M04/020/SEOLHL    │
│  [NEW] 첫표 신규=3건                    │
│  [DELCHK] 삭제 QN=1건                   │
│                                         │
└─────────────────────────────────────────┘
```

### 실행 흐름

#### Step 0: SAP 접속 및 데이터 조회
```
SAP GUI에서 ZQCN, ZNOT 트랜잭션 실행
→ 해당 기간 QN 데이터 조회
→ 텍스트 파일로 내보내기 (자동)
```

#### Step 1: 기존 메일 검색
```
Outlook 보낸 편지함 검색
→ "QN 등록 현황 공유" 키워드 메일 찾기
→ 해당 메일의 스타일 복제
```

#### Step 2-3: C-Type QN 분석
```
Step 2: 신규 QN 감지 및 상세 정보 조회 (QM03)
Step 3: 삭제 QN 판별 및 GUI 표시
```

#### Step 4-5: Q-Type QN 분석
```
Step 4: 신규 Q-Type QN 확인
Step 5: Q-Type 삭제 QN 판별
```

#### Step 6: D-3C/D-5C/D-8 기한 확인
```
ZNOT 트랜잭션 결과 분석
→ 각 QN별 Elapsed Time 추출
→ 메일 표에 반영
```

#### Step 7: KPI 통계 계산
```
D-3C 만족도: [만족 건수] / [전체 건수]
D-5C 만족도: [만족 건수] / [전체 건수]
D-8 만족도: [만족 건수] / [전체 건수]
```

#### Step 8-9: 메일 생성 및 Outlook 열기
```
복제된 메일 본문에:
- 신규 행 추가
- 삭제된 행 제거 (옆에 줄 쳐지고 삭제됨)
- KPI 요약 상단 삽입
→ Outlook 메일 작성 창 열기
```

## 설정 가이드

### 설정 탭

#### 1. SAP Export 디렉토리
```
경로 설정: SAP GUI의 텍스트 파일 내보내기 경로
예시: C:\Users\seolhl\Documents\SAP\SAP GUI

설정 단계
1. [찾아보기] 버튼 클릭
2. 폴더 선택 후 [폴더 선택] 클릭
3. [저장] 버튼으로 설정 저장
```

#### 2. Plant 코드
```
기본값: 2201

SAP 시스템에 따라 변경 필요
- 2201: 기본 생산지
- 다른 코드는 담당자에게 문의
```

#### 3. 메일 수신자
```
형식: email1@company.com; email2@company.com

팁
- 끝에 세미콜론(;) 붙이면 안 됨
- 공백도 제거됨
- 한 명만 입력 후 세미콜론 없이 그대로 저장 가능
```

#### 4. 실행 날짜
```
기본값: 오늘 날짜
선택: 캘린더 아이콘으로 다른 날짜 선택 가능

주의: 과거 날짜 실행 시 기존 메일과 비교
```

#### 5. 파일 템플릿
```
필드별 설명:
- {YYYYMMDD}: 날짜 형식 (예: 20260212)
- _Q1: 두 번째 표 파일 표시

예시:
- First: {YYYYMMDD}.txt → 20260212.txt
- Second: {YYYYMMDD}_Q1.txt → 20260212_Q1.txt
- ZNOT: {YYYYMMDD}_ZNOT.txt → 20260212_ZNOT.txt
```

## 동작 원리

### 신규/삭제 판별 로직

#### Step 1: 파일 비교
```
이전 날짜 파일 (prev_file)
↓
QN 리스트 추출 → {12345678, 12345679, ...}

현재 날짜 파일 (today_file)
↓
QN 리스트 추출 → {12345679, 12345680, ...}

신규 = today - prev = {12345680}
삭제 = prev - today = {12345678}
```

#### Step 2: 폴백 로직 (파일이 없을 때)
```
이전 내보낸 파일이 없으면:
1. 가장 최근 발송 메일 찾기
2. 메일 본문에서 QN 추출
3. 임시 텍스트 파일 생성
4. 동일한 비교 수행
5. 임시 파일 삭제
```

### Outlook 메일 처리

#### 표 업데이트 순서
```
1. 기존 메일의 표 추출
   ├─ 첫 번째 표 (C-Type)
   └─ 두 번째 표 (Q-Type)

2. 삭제 QN 제거
   └─ 해당 행 완전 삭제

3. 신규 QN 행 추가
   ├─ 하단에 신규 행 추가
   └─ No. 자동 재정렬

4. 메일 발송
   └─ Outlook 메일 작성 창 열기
```

## 문제 해결

### 🔴 "No active SAP session found" 오류

**원인**: SAP GUI 미로그인 또는 세션 없음

**해결 방법**:
```
1. SAP Logon 실행
2. 대상 시스템에 로그인 (예: M04)
3. SAP GUI 메인 창 열기 (wnd[0]이라는 윈도우)
4. 프로그램 다시 실행
```

### 🔴 "Outlook MAPI 초기화 실패" 오류

**원인**: Outlook 미설치 또는 COM 연결 실패

**해결 방법**:
```
1. Microsoft Outlook 설치 확인
2. Outlook 메인 창 먼저 열기
3. 보낸 편지함 확인 (메일이 있는지)
4. Outlook 재시작 후 프로그램 다시 실행
```

### 🟡 "[PARSE] 헤더(Notif/Created) 미발견" 경고

**원인**: 내보낸 텍스트 파일 포맷 불일치

**해결 방법**:
```
1. SAP에서 수동으로 한 번 내보내보기 (ZQCN → %PC)
2. 파일 인코딩 확인 (UTF-8이어야 함)
3. Export 디렉토리 경로 재확인
```

### 🟡 메일이 열리지 않음

**원인**: Outlook 실행 중이 아니거나 권한 문제

**해결 방법**:
```
1. Outlook 메인 창을 먼저 실행
2. 보낸 편지함 열기
3. 기존 메일 하나 확인 (로드 시간 필요)
4. 프로그램 다시 실행
```

### 🟡 "비교할 텍스트 파일 없음" 메시지

**원인**: SAP Export 경로에 이전 날짜 파일 없음

**해결 방법**:
```
1. 설정에서 Export 디렉토리 경로 확인
2. 해당 디렉토리에 YYYYMMDD.txt 형식 파일 있는지 확인
3. 없으면 처음 실행이므로 정상 (메일 기반 폴백 작동)
```

## 자주 묻는 질문

### Q1: 매번 설정을 입력해야 하나요?
**A**: 아니요. 첫 실행 후 설정이 저장되어 다음 실행 시 자동으로 로드됩니다.

### Q2: 메일을 먼저 확인해야 하나요?
**A**: 네, 가장 최근 메일을 기준으로 스타일을 복제하므로 이전 메일이 있어야 자동화됩니다.

### Q3: 오류 없이 완료되려면 몇 분이 걸리나요?
**A**: SAP 데이터 규모에 따라 다르지만, 평균 **5~15분**입니다.

### Q4: 데이터를 임의로 수정할 수 있나요?
**A**: 네, 메일 작성 창이 열리므로 발송 전에 아무거나 수정 가능합니다.

### Q5: 같은 날짜로 여러 번 실행하면?
**A**: 같은 내보낸 파일을 재사용하므로 신규/삭제 결과가 동일합니다.
